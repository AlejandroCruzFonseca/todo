# React Todo List

Todo lists are common starter projects because they cover the fundamentals: rendering lists, handling input, and implementing basic CRUD features. You will use React hooks, manage state, and handle user input. Basic JavaScript knowledge matters here.

## Prerequisites

- HTML
- CSS
- JavaScript
- Node.js
- npm

## Stack suggested

- React
- npm
- Next.js
- MUI
- Jest

## Requirements

- Create Tasks and store them in localStorage.
- Read Tasks from localStorage and display them.
- Update Tasks in localStorage and display the update.
- Delete Tasks tasks from localStorage and remove from list.
- Add filter for active tasks.
- Add a filter for completed tasks.
- Add tags and a search bar.
- Implement drag and drop ordering.
- Keyboard shortcuts.
- Empty state messaging.

### All requirements should comply with

 - Unit Tests
 - Accessibility labels.
 - ADA compliance.
